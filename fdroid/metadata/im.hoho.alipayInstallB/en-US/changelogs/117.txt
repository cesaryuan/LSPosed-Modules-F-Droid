- 提供首个在线主题示例：HOHO 黑钻主题（深色基调，覆盖首页 / 财富 / 生活 / 消息 / 我的 全套）

## English

- Theme tab now has an **Online Themes** entry that pulls themes from GitHub
- First sample theme included: HOHO Black-Diamond (dark, full home/wealth/living/message/me set)
- Remote manifest parser is backward-compatible (older builds keep working unchanged)
