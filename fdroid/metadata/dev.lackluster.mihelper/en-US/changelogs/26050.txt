## What's Changed
- Migrated to the **Modern Xposed Module API (Libxposed API 101)**
- **XSharedPreferences** has been deprecated. As a result, all existing configurations will be lost after updating. Please back up your settings in advance and reconfigure them after the update  
- Added support for **HyperOS 3.0 (including 3.0.300+)**. This version is intended **only for HyperOS 3**; support for HyperOS 2 and earlier has been removed  
- New feature: **System UI → Icon customizer → Dual-row signal icons**  
- New feature: **System UI → Icon tuner → Combined icons**  
- New feature: **System UI → Icon tuner → Shift status bar icons to the left**  
- New feature: **System UI → Single / double tap on empty area to trigger specific actions**  
- Numerous behavior tweaks and refinements have been made and are not fully listed here—feel free to explore  
- Join our [Telegram channel](https://t.me/lackluster_stuff) to report issues, get insider builds, and stay up to date with future releases
